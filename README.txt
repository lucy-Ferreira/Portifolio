PORTFÓLIO — LUCY FERREIRA

Como visualizar:
1. Extraia o arquivo ZIP.
2. Abra o arquivo index.html no navegador.

Para personalizar:
- As fotos estão em assets/.
- Os cartões da seção "Vídeos" são espaços reservados para seus links.
- O conteúdo, Instagram, TikTok e e-mail já estão configurados.
- O site é responsivo para computador e celular.

Para publicar:
Você pode colocar a pasta em serviços de hospedagem de sites estáticos, como GitHub Pages, Netlify ou Vercel.
